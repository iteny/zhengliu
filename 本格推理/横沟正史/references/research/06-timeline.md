> 用途：为「横沟正史视角」技能提供可核查的生平骨架。
> 体例：只收录能追到具体出处的节点；年份精确到月，能到日就到日。凡中文维基／日文维基与辞书、报纸冲突，主表取辞书／报纸，并在「版本冲突记录」中并列。
> 来源等级：**A＝辞书/报纸/出版社官方**；**B＝图书馆书目、作品初出目录、美术馆/自治体资料**；**C＝维基类（仅作线索，已尽量回查）**。
> 黑名单：知乎、微信公众号、百度百科（本次未作为任何节点的依据）。
> 调查截止：2026-10-21。

## 版本冲突记录（辞书／报纸 vs 维基）

1. **生日**：日文维基系谱与中文维基、英文维基均作5月24日；《20世紀日本人名事典》《デジタル版 日本人名大辞典+Plus》《367日誕生日大事典》作5月25日；《ブリタニカ国際大百科事典》作5月24日。→ 主表取「5月25日（辞书多数）」，并保留24日异说。**未能核到戸籍或新闻讣告的一手日期**。
2. **《新青年》编辑长就任**：部分中文资料作「1927年，25岁」，コトバンク另处作「1928年、森下雨村の跡を継ぎ」。城邦年谱明确「1927年5月接任主编」。→ 取1927年5月，1928年说可能是「正式接掌」或误记。
3. **疗养地**：中文资料多作「1934年7月，长野县八岳山麓富士见高原疗养所」。城邦年谱显示：1933年7月入**富士见**疗养所约3个月，1934年7月转**上诹访**疗养约5年。→ 两者是先后两段，不可合并。
4. **疎開地**：中文维基只写「1945年4月之后，搬到冈山县居住三年」；中文维基「本陣殺人事件」条与朝日新闻均作「吉备郡冈田村（今仓敷市真备町冈田）」。→ 「児島郡味野町」说无一手依据，见「未核存疑」。
5. **奖项名称**：中文普遍以「日本推理作家协会奖」回溯称呼1948年获奖。历史上1948年是「日本探偵作家クラブ賞」。→ 主表用当时名称，并注现名。

## 一句话骨架

**1921年4月以《恐ろしき四月馬鹿》出道 → 1925年4月见乱步 → 1926年6月入博文馆 → 1927年5月任《新青年》编辑长、同年结婚 → 1932年退社专写 → 1933年喀血、1934年转上诹访疗养五年 → 1945年4月1日疎開冈山吉备郡冈田村 → 1946年4月《本陣殺人事件》创刊号、金田一诞生 → 1948年第1回探偵作家クラブ賞 → 1950年代《犬神家》《女王蜂》《悪魔が来りて笛を吹く》《悪魔の手毬唄》 → 1963–1973断笔 → 1976年《犬神家》电影＋勲三等瑞宝章 → 1981年12月28日结肠癌去世（79岁） → 2006年山梨「横溝正史館」 → 2022年生诞120年 → 2026年NHK《悪魔の手毬唄》、电影《八つ墓村》。**
