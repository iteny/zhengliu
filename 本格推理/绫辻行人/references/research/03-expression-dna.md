## 0. 一句话结论

綾辻行人的文体不是「文笔型文体」，而是**「装置型文体」**：他的个性不落在词汇和句法上，而落在一组**可复制、可命名的形式装置**上——卷首折入的平面图、「〇〇館の殺人」的命名轴、双线交替的章节标签、以及依赖「绰号/本名」双轨命名成立的叙述性诡计。他自己把这套东西的创作方针说得很白：**他是把自己当读者的**。

> 【日·高】「僕はもともとミステリファン上がりの作家なので、自分が読者だったらどう感じるかな、という気持ちでいつも本を作ります。」
> —— 楽天ブックス 著者インタビュー，2012-03-08
> https://books.rakuten.co.jp/event/book/interview/20120308-ayatsuji-yukito/

**这条自述是整个 03 号报告的锚点。** 后面所有装置都能从它推导出来。

## 1. 三个最鲜明的文体特征（Top 3）

### ① 卷首折入的「平面図」——把图纸做成正文的前置器官

**事实层**
- 【日·高】「館」シリーズといえば、**巻頭に折り込まれる平面図**も特徴ですね。
- 【日·高】綾辻本人说法：「自分が読者だった時、平面図が付いた本を読むのがすごく楽しかったので、やっぱりあったほうがいいだろうと。それにこういう物語って、**文章でひたすら説明するよりも、ぽんと平面図を出しちゃったほうがわかりやすい**ですしね。」
- 【日·高】图纸制作流程：「平面図は毎回、家人の小野不由美に手伝ってもらいながら作っているんですよ。……執筆と並行して図面のラフを作成していって、最終的な仕上げは小野さんにお願いしています。」
- 【日·高】系列轴的设计动机：「同じ名探偵が事件に挑むシリーズはたくさんあるけれども、**殺人の舞台となる建物を設計した建築家が同じ**、というシリーズは前例がない。そう思いついたわけです。**名探偵を固定しないこと**でいろんなことができそうだな、というふうにも。」
> 全部出自：https://books.rakuten.co.jp/event/book/interview/20120308-ayatsuji-yukito/

- 【译·中】中文出版方与台湾媒体补充：图纸绘制者为小野不由美；绫辻在《雾越邸杀人事件》卷首谢词写「献给另一位中村青司先生」，并在访谈中承认「其实就是小野不由美女士（笑）」「《雾越邸》里的图纸也是，而且有关建筑物的构思与构造本身就是她的想法」。
  https://www.sohu.com/a/200140265_252338 （载体为内容聚合站，可信度打折；核心信息——夫人绘图——与日文访谈互证，故取信）
- 【译·中】台湾 OKAPI 作家专题（2017，出道三十年）：馆系列「附有平面圖，書中的平面圖由家中開設建築事務所的小野不由美繪製」「這種史無前例的特殊寫法獨樹一幟」。
  https://www.okapi.books.com.tw/article/11350

**文体意义（推）**
1. **图纸取代了描写。** 绫辻明确说：与其用文章解释，不如「啪」地摊一张图。这意味着馆系列的**空间描写是被刻意卸载的**——描写成本转移给了图纸，正文因此可以把篇幅让给对话与推理。这是理解他「描写密度低」的证据链起点。
2. **先给图、再给人。** 读者在见到人物之前先见到建筑的几何形状，叙事顺序被固定为「空间 → 人物 → 事件」。这与横沟正史式「先人后屋」相反。
3. **图纸是公平的担保物。** 新本格讲究读者与侦探同一起跑线；平面图把这个承诺从文字层面搬到了**页边实物**层面。
4. **夫妻分工即文体分工。** 建筑图（非文字）由他人完成，文字由绫辻完成——他的系列从物质生产层面就是「文字 + 图纸」的混合体。

### ② 「文字だからこそできるトリック」——把诡计焊死在文字媒介上

**事实层（本报告最硬的一条日文原话）**
> 【日·高】
> ──その『Another』は現在TVアニメ化され大変な反響を呼んでいますが、「館」シリーズはこれまでほぼ映像化されていませんね。
> 綾辻さん：**基本、映像化は不可能ですから（笑）。**典型的なのが『十角館の殺人』。実は昔、映像化の企画が何度か来たことがあるんですが、「どうやってこのトリックを実現させるんですか?」と質問して、ちゃんとした答えが返ってきたことは一度もありませんでした。**「館」シリーズは「文字だからこそできるトリック」を意識して取り入れている**ので、映像化が難しいのは当然といえば当然。
> —— 楽天ブックス，2012-03-08，同上 URL

**这条自述把「文字媒介性」提升成了创作纲领。** 注意动词是「意識して取り入れている」——不是结果，是意图。

**具体机制（《十角馆》的绰号/本名双轨）**
- 【译·中，实为日文原作情节】岛上章人物一律以推理作家绰号相称（范达因 Van、艾勒里 Ellery、阿加莎 Agatha、卡尔 Carr、勒鲁 Leroux、艾伦·坡 Poe、奥希兹 Orczy）；本土章人物一律以本名相称（江南、岛田、守须）。读者自然把两组当成两拨人。
- 破局的那一行（剧透）：【译·中/日文二次源·中】守须恭一被问到绰号时回答 **「ヴァン・ダインです」**（我是范达因）。
  https://ellemamateaparty.com/?p=7435 （日文剧评，转述原作）
  https://note.com/vast_viola153/n/nfed2c0e1c1a1 （note 日文长文，英文界面但正文为日文）
- **机制本质**：【推】这个诡计**不需要任何物理伪装**，只需要两套命名系统 + 读者对「同一本书内两条线遵循同一套命名逻辑」的默认。它欺骗的对象不是书中的侦探（侦探从未被骗），**是读者本人**。
- 【译·中】绫辻对漫画化的松口：「如果是漫画，就有可能」——理由是漫画可以用分镜/构图控制读者「看到什么」而不「注意到什么」。
  https://www.sohu.com/a/923804097_583972 （内容聚合站，可信度中低，但与 2019 年起清原紘版《十角館》漫画连载这一可核事实吻合）

**为什么它依赖文字（推，四层）**
1. **文字没有脸。** 文字里「ヴァン」和「守須」是两个字符串，读者不会自动做人脸匹配。
2. **文字的指称是可替换的。** 影像中指称被演员的肉身锁死，文字中指称只是标签，作者可以任意换标签而不露痕迹。
3. **文字是线性且不可回看的（相对）。** 读者无法像看画面那样一帧内同时比对两条线。
4. **文字允许「不说」。** 影像必须填满画面（镜头必然拍到一张脸），文字可以选择不说——「不说」本身就是绫辻最经济的诡计材料。

### ③ 双线交替 + 章名标签化——把叙事节奏做成可外显的节拍器

**文体意义（推）**
1. **章名即导航仪表盘。** 他的章名不做抒情（不是「夜」「雨」），而是做**坐标**——天/地、现在/过去、月份、其一/其二。读者翻到章名就知道自己在哪条线、哪个时间点。
2. **标签的消失即信息。** 十角馆第 9 章起突然只写「第五天」，不写岛/本土。这是用**目录级别的形式变化**释放信号，而不是用文内提示。
3. **交替是节拍器。** 双线交替保证了「悬念不被消耗」——一条线紧绷时切到另一条线松弛，形成可预测的呼吸感。这是他长篇（尤其 1000 页级的《暗黑馆》）能读下去的技术前提。
4. **章名风格随作品对象切换。** 暗黑馆用四字抽象名词（雾/耳语/影/庆典），惊吓馆用「惊吓馆的○○」的低龄童话口吻，人形馆用月份的日记体。**章名是他调整语体的第一道旋钮**——这一点对 Skill 生成极有价值。

## 2. 分论点展开

### 2.1 「館」命名法：十角/水車/迷路/人形/時計/黒猫/暗黒/びっくり/奇面/双子

**命名轴的形态（结构层，可核）**

日文原题一律为 **`〇〇館の殺人`**：
十角館 / 水車館 / 迷路館 / 人形館 / 時計館 / 黒猫館 / 暗黒館 / びっくり館 / 奇面館 / 双子館
（第 10 部《双子館の殺人》自 2023 年 7 月起在讲谈社《梅菲斯特》连载）
https://www.wikiwand.com/zh-cn/articles/綾辻行人 【译·中，zh-wiki 镜像】

**命名法的三条规律（推）**
1. **构词是「名词定语 + 館」，定语分三类：**
   - 几何/形状：十角、双子
   - 机械/装置：水車、時計、びっくり（惊吓箱）
   - 人形/动物/色彩：人形、黒猫、暗黒、奇面、迷路
   → 即：**每一部必须自带一个可画成图的「形」。** 这是平面图装置的命名学前提——名字先保证了「有图可画」。
2. **びっくり館是唯一平假名馆名。** 【译·结构·中】其余九部为汉字。这个破例与它的童话/儿童视角语体同步（章名全用「惊吓馆的○○」），说明命名与语体是联动的。
3. **中文译名统一改成「〇〇馆事件」，日文原题是「〇〇館の殺人」。**
   【译·中】中文版统一改题（据 zh-wiki 镜像与各书商页）。这是一个**可迁移性教训**：日文原题的「殺人」二字是类型承诺（杀人 = 本格），中文「事件」二字是中性化承诺；造人 Skill 在日语语境应用时，**书名本身要承担类型承诺**，这一点中文译名会丢失。

**中村青司作为系列轴（日文原话）**
> 【日·高】「殺人の舞台となる建物を設計した建築家が同じ、というシリーズは前例がない。」
> 【日·高】「名探偵を固定しないことでいろんなことができそうだな」
> —— 楽天ブックス 2012-03-08

**推**：这两句合起来是一个完整的文体设计决策——**他不固定「谁在看」，只固定「看什么」**。系列的可识别性从「侦探人格」转移到「空间人格」。这直接导致了馆系列没有贯穿的人格化叙述者（与岛田庄司的御手洗洁、横沟的金田一耕助根本对立）。

- 【译·低·载体为内容聚合站】绫辻另一次回答同一问题：「一开始并没有做什么预设，只是出于『设定上比较方便』的考虑而已。但在写《暗黑馆事件》的时候，已经对中村青司这个人物有感情了。」——以及对「为什么偏好密室」的回答：「与其说『密室』，不如说是在『闭塞的环境』中发生的事件。这是个人的喜好。没有警察等外人介入，可以构筑纯粹的『推理物语』……另外，在『封闭状态』下产生的恐怖与悬疑也是我喜欢的。」
  https://www.sohu.com/a/314908130_563923 （《知日》中文专访转载；日文原刊未取到，标【译·低】）
  **「閉塞した環境」「閉じた状態」这两个词如果拿到日文原文，是第 4 节（恐怖 vs 解谜）的关键引语。目前只能标为待核。**

**核心洞察（推）**
1. **他的叙述性诡计不靠「说谎」，靠「默认」。** 作者不说假话，读者自己补完。这决定了他文体的**极度规范性**——句子不能有歧义、不能有含糊，否则读者会怀疑叙述本身。他的文字必须「干净到不引起怀疑」。
2. **视角切换 = 诡计载体，也是节奏载体。** 双线交替既是节拍器（2.3），也是诡计容器（本节）。**形式装置在他身上是复用的一一装置多用，不是一用一装置。**
3. **《Another》是视角装置的变体**：【译·中】榊原恒一的一人称少年视角，「以十四歲小孩的敘事觀點……與家人、同學之間的互動都讓人感到溫馨又可愛」，读者跟着这个受限视角被牵着走。
   https://vocus.cc/article/68b540a6fd89780001e6700e 【译·中】
   https://www.tuili.com/blog/u/2112/archives/2012/5270.html 【译·中，推理之门书评：「上部基本也就这两个人在互动……上部被读者普遍认为很『水』」「本書分為上下兩部份」「第一部分主要是敘述了主角來到夜見山中學後的所見所聞」】
   - 【译·中】有读者指出《Another》的叙诡在动画化时失效：「《替身》裡面最重要的那處敘詭……小說裡是完全看不出來的，在《Another》動畫裡卻一看就知道了」
     https://www.qinggua.com/article?id=86309 【译·中】
     **这条是「文字才能实现的诡计」的负向证据（影像一拍就破），与 2.1 的正向自述互为印证。**

### 2.3 「文字才能实现的诡计」的文体特征（小结）

【推】把 2.1 与 2.2 合并，可以抽出「文字依赖型诡计」的四条文体特征：

1. **指称系统的可分裂性**——同一实体在两个语境里被叫两个名字（绰号/本名、手记内/手记外、旧馆/新馆）。文体上要求**命名高度一致且从不自我解释**。
2. **信息缺省的正当性**——文字可以不说（不描写长相、不交代姓名），影像不能。文体上要求**描写被刻意削减到诡计需要的最低限度**。
3. **章节层的形式信号**——诡计的伏笔不藏在句子里，藏在**目录里**（十角馆第 9 章标签脱落）。文体上要求**结构本身是文本的一部分**。
4. **读者的线性时间**——诡计依赖读者「一路向前读、不回头比对」。文体上要求**高可读性、高推进速度**，不能有让读者停下来品味的滞重段落。

→ **这四条共同推出一个文风结论：绫辻的文句应当是「快、干净、透明、不自我炫耀」的。** 任何文笔上的存在感都会破坏诡计。
**但这条推论与一部分读者观察冲突（见 2.5），冲突本身要保留。**

### 2.4 恐怖与解谜的混合：两套语体

**A. 馆系列（解谜侧）**
- 语体承诺：本格解谜 → 作者本人在中文版序里写明。
  【译·中，作者自述·中高】「"馆系列"作品着眼于"不可解的谜团与理论性的解谜"，属于通常意义上的"本格推理"小说。完成一部作品的方法有很多，除了重视这些着眼点以外，**我一以贯之的目的，就是能写出具有"意外结局"的作品。当大家阅读到各个作品的结局时，如果能在"啊"的一声之后感到惊讶，对我来说就十分幸福了。**」
  —— 绫辻行人 2013 年 3 月《致中国读者》（载 新星出版社《钟表馆事件（修订版）》等卷首）
  https://product.m.dangdang.com/detail23974659-0-1.html 【译·中，书店页转载；原为作者为中文版所作序言，非日文原文】
  **注意这句自述的重要性：他的目标函数不是「写得美」，是「让读者啊一声」。这是「装置型文体」的终极自白。**
- 恐怖来源：**空间**（封闭、暗道、机关、形状）。

**B. 耳语三部曲 / 殺人鬼 / Another（恐怖侧）**
- 耳语系列的命名轴是**颜色**：緋色の囁き（1988）/ 暗闇の囁き（1989）/ 黄昏の囁き（1993）。
  【译·中】台湾 OKAPI：「若說館系列是藉由外在空間所凝聚的恐怖，那麼耳語系列的特點便於在於**內心描摹和感受的可怕**。以顏色為區別，有紅色、黑色及黃昏的色系意象。」
  https://www.okapi.books.com.tw/article/11350
  **【推】这是最漂亮的一处对仗：馆系列用「形」做轴（可画成平面图），耳语系列用「色」做轴（不可画成图，只可感受）。同一作者的两种语体，恰好对应「可绘 / 不可绘」。**
- 殺人鬼系列：感官恐怖，读者体感证据。
  【译·中】台湾博客来读者书评（繁中）：「從文字的描述中完全可以激發出同等的場景、畫面」「讀者就像書中的角色一樣『沒有喘息的餘地』，文字可以咀嚼的跟書中人物一樣充分體會緊張、刺激、恐懼」「個人覺得是一本十分精采的**黑色官能小說**」
  https://www.books.com.tw/booksComment/getCommemt/0010171479 【译·中，读者 UGC，但为繁中一手读后感，可作语体体感的旁证】
- Another：恐怖 / 推理 / 青春日常的三角混合。
  【译·中】「明明是驚悚小說，角色卻很可愛；明明是給青少年看的推理作品，卻一度出現極度血腥恐怖的死亡現場」
  https://vocus.cc/article/68b540a6fd89780001e6700e
  【译·中】「平時我對於日本青春校園風格的作品都沒什麼興趣，但……竟然好喜歡《Another》裡面那些**青春洋溢、小中二但是又讓人會心一笑的日常對話**！……我以前覺得綾辻行人的文筆……就是**平鋪直敘、沒什麼突出之處**；沒想到在《Another》當中，綾辻老師發揮出十足的文采……讓我懷疑到底是不是同一個人寫的」
  同上 URL。【译·中】**这条读者观察极有价值：同一个读者认为他在《Another》里「文笔变好」，说明他的语体是随作品对象主动切换的，而不是恒定的。**

**两套语体对照表（推）**

| | 馆系列 | 耳语/杀人鬼/Another |
|---|---|---|
| 恐怖来源 | 外部空间（馆的形状、暗道、封闭） | 内部感受（心理、身体、超自然） |
| 命名轴 | 形（十角/時計…）——可绘图 | 色（緋/暗闇/黄昏）——不可绘图 |
| 章名 | 坐标式（天数、现在/过去、月份） | 情感式/事件式 |
| 卷首装置 | 平面图 | 无 |
| 目标读者反应 | 「啊」一声（知性游戏） | 发抖 / 不敢独处 |
| 与影像的关系 | 不可影像化 | 可影像化（Another 已动画/真人化） |

  https://dorispace.com/murder-at-decagon 【译·中，繁中长篇读后感】

**【推·未定论】** 两个观察可以是同一事实的两面：
- **对话密度高**（「琐碎的谈话占据大量篇幅」）→ 与「不写询问证词」不矛盾：他写的是**同辈闲聊**（学生社团的废话），不是**程序化问询**。目的都是「让读者和人物平等」，手段是闲聊而非审讯。
- **描写时快时慢**：对话段落快速推进，环境段落偶有慢镜头。《十角馆》序章（单独一人坐在防波堤上）就有大段内心独白——**慢镜头集中在「序章/人物独处」处，快镜头集中在「群戏/对话」处**。这需要日文原文验证，标为**假设**。

**C. 高频用词（语汇层）——无法给出可核清单，只能给假设**

【假设·未验证】基于中文译本的三条弱推断，造人 Skill 使用时须标注为「未在日文原文上验证」：
1. **时间词密度极高**：章名层面已经证明（天数、现在/过去、月份、1990年6月·东京）。【推】正文层面应延续这一习惯——叙事靠时间戳推进，而非靠情绪推进。
2. **空间词 > 心理词**：卷首平面图把空间描写外包后，正文中的空间词应多为**指路型**（走廊尽头、左手第二间、地下）而非**氛围型**。
3. **句长偏短、对话占比高**：由「对话密度高 + 描写节约」两条读者观察共同指向。

https://book.kongfz.com/400890/6755277156/ 【译·中】
**可读出的结构层特征（推）**：

2. **三段式排比推进时间**：好几个月 / 好几个星期 / 好几天 → 由远及近的收束，是典型的推理小说「计划成型」独白。
3. **抽象名词作结论**：「最理想的计划不是制约自己的行动，而是极具"柔软性"的随机应变」——**用概念词收束，不用意象收束**。
4. **视角是「他」+ 极近距离**（能写出「嘴里不断呼出白气」）→ 三人称限定视角，紧贴但非一人称。

> 为了躲避滂沱大雨，江南孝明大步跑进那座好不容易才找到的建筑物里。随后，他从上衣口袋里取出怀表看了看。这表是两年前去世的祖父留给他的遗物，从那之后，他便一直用着这块表，而不再戴手表了。

> ……
> 他一边用力甩掉折好的伞上的雨滴，一边环视着这座昏暗建筑的内部。他如今所在的位置，是一座名为"Green Heights"的公寓的门厅，它建在东京世田谷区上野毛一条幽静的住宅街上。

https://product.m.dangdang.com/detail23974659-0-1.html 【译·中】

**可读出的特征（推）**：

2. **列举式堆砌**：牌桌上、扶手椅上、壁橱里、暖炉里、床上…… → **用名词清单制造密度**，与 2.6「新本格宣言」的名词清单句式同源。

## 5. 造人 Skill 可直接取用的「绫辻式表达模板」（推）

> 以下为**从证据推出的可操作模板**，不是引用。使用时建议标注为「基于结构层证据的推演」。

**T1 · 装置先行**
写任何长篇前，先确定一个**可命名、可画图的空间装置**（形状 / 机械 / 色彩），并让它的名字成为作品名。
> 依据：【日】「平面図を出しちゃったほうがわかりやすい」+ 十馆命名法。

**T2 · 坐标式章名**
章名不做抒情，做导航。可选四种轴：**天数 × 地点 / 现在 × 过去 / 月份 / 篇目编号**。标签的**消失**可以当信号用。
> 依据：全系列目次（结构层，多源一致）。

**T3 · 名词清单式宣言**
人物表达偏好时，用并列名词清单 + 最后一句价值观收束：
「要数 A、B、C、D、E、F……虽然荒诞无稽，但是没关系，最重要的是在其中的○○。」
> 依据：【译·中低】十角馆内新本格宣言。

**T4 · 双轨命名**
让同一人物在两个语境中拥有两个名字（绰号/本名、手记内/外），两套系统互不解释，直到最后一刻并轨。
> 依据：【日】文字才能实现的诡计 + 十角馆机制。

**T5 · 目标函数是「啊一声」**
写作目标设定为「读者在结局发出一声惊叹」，而非「文字美」。
> 依据：【译·中高】作者中文版序自述。

**T6 · 语体随对象切换**
章名、人称、卷首装置三者同步切换：严肃解谜 → 坐标章名 + 三人称 + 有图；恐怖 → 情感章名 + 一人称体感 + 无图。
> 依据：馆系列 vs 耳语/Another 的对照表（2.4）。

## 6. 文体判断的局限（必读）

**L1 · 最致命的一条：日文原文正文一条都拿不到。**
綾辻行人 1960 年生、健在，全部作品在著作权保护期内，**青空文庫无一字收录**，讲谈社/角川亦无公开立ち読み长文。本次检索中，能从日文页面逐字引用的**只有访谈（楽天ブックス 2012）与新闻报道（ORICON 2024）**，小说正文**零原文**。
→ 因此：**本报告在「结构层 / 装置层 / 作者自述层」是可靠的；在「用词、句法、句末形态、敬体常体、拟声拟态词、文语残留」等语汇层，一条硬证据都没有。** 2.5 节 C 项的三条用词假设必须当作假设使用。

**L2 · 中译本≠日文原文，且中译本自身经过了出版社的类型改造。**
一个可观察的证据：日文原题 `〇〇館の殺人`（类型承诺 = 杀人），中文统一改题 `〇〇馆事件`（承诺被中性化）。书名被改，说明**译本整体是面向中文市场重做过的产品**——目录结构可信（物理结构），但句子节奏、对话口气、描写密度都经过译者与编辑的再加工。S1–S4 四个样本**只能读结构，不能读语汇**。

**L3 · 「破局一行」只有日文二次源，没有书页级证据。**
「ヴァン・ダインです」这五个字出现在日文剧评与日文 note 长文中，但**没有一次出现在可直接核对的原书扫描/官方引用里**。它作为例子是高度可信的（多源一致且细节吻合），但严格说仍是二次源。

**L4 · 最想要的两条日文原文本次未取到。**
- 新本格定义的日文原话（只有三源互证的中译文，译文高度一致，可信度提到中高，但终究是译文）。
- 「閉塞した環境」「閉じた状態」的日文采访原文（只有《知日》中文转载）。
→ 若后续能拿到日文《知日》或讲谈社官方访谈页，这两条应立刻升级并替换现有【译】标记。

**L5 · 读者观察互相打架，本报告选择保留冲突而非调和。**
「描写节约 / 平铺直叙」与「文字慢镜头 / 琐碎谈话占大量篇幅」两组观察来自不同读者、不同作品（前者多为馆系列整体印象，后者专指《十角馆》前三分之一）。我给出的调和（对话快、独处慢）只是**一个未经检验的假设**，不是结论。

**L6 · 人称信息几乎全部来自 UGC。**
各卷的一人称/三人称判定来自读者题注、人物介绍表、百科，没有一条来自日文原文或官方内容梗概。2.2 的表格**结构列可采信，人称列须存疑**。

**L7 · 时间/媒介偏倚。**
本次检索命中的日文页面大量是**剧集化（2024 Hulu《十角館の殺人》、2026《時計館》）**相关的报道与剧评。这意味着「哪些事实被日文互联网反复提及」受 2024–2026 的影视化周期影响，「映像化不可能」这句话的曝光率被显著放大。**它可能不是他最核心的自述，只是最容易被转引的一句。**

**L8 · 「新本格七大守则」已判定不采信，勿在 Skill 中使用。**
中文百科集群同源复制，日文侧零佐证。若 Skill 需要「新本格规则」类素材，应改用**可核的绫辻本人新本格定义**（抛开狭隘现实性……）与**作者自述的目标函数**（「啊的一声」）。

**L9 · 不可迁移的部分。**
绫辻最核心的装置（卷首图纸、双轨命名、文字媒介诡计）都**高度依赖长篇篇幅与读者线性阅读**。若 Skill 用于生成短文本（短文、对话、社媒），这些装置大部分失效，只有 T3（名词清单式宣言）与 T2 的简化版可迁移。
